# Asif Anwar – Personal Project Repository

This repository showcases a curated collection of my technical projects and coursework spanning nuclear engineering, scientific computing, and data visualization. These projects were developed during my free time of my graduate studies at Purdue University and reflect my passion for computational modeling, reactor systems, and interdisciplinary problem-solving.

---

## Project Directory

| **Project Title**             | **Technologies**                        | **Description** |
|------------------------------|----------------------------------------|-----------------|
| **Reactor Data Dashboard**   | Python, Streamlit, Plotly, Pandas, CSV | Built an interactive, fault-tolerant dashboard that parses real or simulated reactor logs (power, rod position, flow) and displays KPI trends, heatmaps, and anomaly alerts for educational or monitoring purposes. Emulates a reactor control room experience using minimal data. |
| **Monte Carlo Shielding Simulator** | Python, NumPy, Matplotlib, SciPy       | Developed a Monte Carlo simulation for modeling gamma attenuation in shielding materials. Generates depth-dose curves, 2D dose maps, and visualizes dose reduction across configurations. Validated results using Beer–Lambert Law. Applicable for both terrestrial and spacecraft shielding. |
